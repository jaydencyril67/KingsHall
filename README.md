# KingsHall

Fresh frontend foundation built with **Vite + React + TypeScript**.

## Commands
- `npm install` — install dependencies
- `npm run dev` — start the Vite development server
- `npm run build` — type-check TypeScript and build production assets
- `npm run preview` — preview the production build locally

## Current scope
- Responsive KingsHall landing page with Login and Sign Up modes.
- React-controlled tabs and submit feedback; browser-side input validation.
- No API calls, backend, database, authentication, cookies, or credential storage.
- Submitting either form only shows a notice; no details are sent or saved.

Authentication will be added later as a separate, reviewed milestone.
