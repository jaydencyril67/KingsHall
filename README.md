# KingsHall

Fresh frontend foundation built with **Vite + React + TypeScript**, with a minimal Capacitor Android wrapper for staged APK testing.

## Frontend commands
- `npm install` — install dependencies
- `npm run dev` — start Vite
- `npm run build` — type-check and build production assets

## Android APK test
The GitHub Actions workflow **KingsHall Android APK** builds a diagnostic **debug APK** when manually started or when relevant frontend files change on `main`. Download the `KingsHall-foundation-debug-apk` artifact from the workflow run.

The Android wrapper is generated by Capacitor in CI; it is not committed as a pre-generated Android project. The diagnostic app uses the separate package ID `online.kingshall.foundation` so this first test can be distinguished from previous KingsHall APKs.

## Current scope
- Login and Sign Up are visual React forms only.
- No backend, authentication, API requests, or credential storage.
- The APK is a test build, not a production release.
- Play Protect results must be checked on the actual downloaded APK/device; a successful build does not prove an app is safe or guarantee Play Protect approval.
