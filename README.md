# KingsHall — fresh landing page

A dependency-free static landing page with Login and Sign Up sections.

## Current scope
- Responsive KingsHall landing page.
- Login and signup tabs with browser-side validation.
- No API calls, backend, database, account creation, authentication, cookies, or storage.
- Form submission displays an explanatory message and does not send or save credentials.

## Deployment
Serve `index.html` directly from the repository root using a static hosting provider. No build command or dependency installation is required.

Authentication will be added later as a separate, reviewed milestone.
